# Product Specification: AI Art Curator & Catalog

## 1. Value Proposition
Сервис для галеристов, кураторов и коллекционеров, который превращает хаос из изображений и имен художников в структурированную базу данных с автоматическим AI-анализом, глубокими описаниями и инструментами презентации.

## 2. MVP Scope (3 ключевые фичи)
1. **Мультимодальный импорт:** Загрузка фото произведений искусства с авто-извлечением метаданных через AI (автор, эпоха, визуальные характеристики).
2. **AI-куратор / Интеллектуальный поиск:** Фильтрация и поиск по каталогу с помощью текстовых/концептуальных запросов пользователя.
3. **Генератор презентаций:** Формирование аккуратной подборки/каталога выбранных объектов для презентации клиентам.

## 3. Tech Stack
- Frontend / Framework: Next.js (React)
- Styling: Tailwind CSS
- Database & Auth: Supabase (PostgreSQL + Row Level Security)
- AI Integration: OpenAI API / Gemini API для мультимодального анализа и структурированного вывода (Structured Output)
- Hosting: Vercel
